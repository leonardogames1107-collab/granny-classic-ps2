Granny Classic PS2

Projeto homebrew para PlayStation 2.

Objetivo

Recriar Granny Classic, inspirado nas primeiras versões do jogo original para PC e celular.

Características

- Casa clássica original.
- Jogabilidade em primeira pessoa.
- Granny com inteligência artificial.
- Cinco dias para escapar.
- Chaves, ferramentas e enigmas.
- Esconderijos em armários e camas.
- Sons e perseguições clássicas.

Aranhas

- Manter a aranha do último andar (sótão).
- Remover a aranha do esgoto.
- Preservar os demais elementos clássicos.

Plataforma

- PlayStation 2 Slim.
- Controles DualShock 2.
- Execução homebrew pelo uLaunchELF.
- Formato executável ELF.

Objetivo técnico

Criar uma versão jogável para PlayStation 2, com gráficos 3D adaptados ao hardware do console.
